# 模型调用与费用依据

核对日期：2026-10-31。实现使用 HTTPX 发出 OpenAI 格式 Chat Completions 请求。默认模型 `deepseek-flash`，官方地址 `https://api.deepseek.com/chat/completions`；显式关闭思考模式以控制单次生成量。世界回复启用 `response_format: {"type":"json_object"}`，提示词同时要求 JSON，程序再验证字段。API 临时玩家返回普通自然语言行动。

官方资料：

- [DeepSeek 模型与人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
- [Chat Completions 请求和用量字段](https://api-docs.deepseek.com/api/create-chat-completion/)
- [国务院办公厅 2026 年节假日通知（北京市政府发布）](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)

人民币价格集中在 `content/pricing.json`，单位为每百万 Token。Flash 空闲时段缓存命中/未命中/输出分别为 0.02/1/4 元，高峰时段为 0.04/2/8 元。Pro 对应为 0.15/4.5/13.5 元与 0.30/9/27 元。

北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰，排除中国节假日；周末全天空闲。周末调休上班仍按官方周末规则处理。内置日历仅核对了 2026 年：其他年份可能的工作日高峰按高峰价保守估算，并显示日历缺口。未来请更新价格与日历，不能把历史快照当成永久价格保证。

用量取自服务商实际响应的输入、输出、缓存命中与未命中字段；未知项保留 `null`。用量齐全但缓存分项缺失时，按全部未命中估算。请求跨越不同计费时段时保守采用高峰价。费用是本地计算的估算，不是平台账单或已入账金额。MCP 只能统计 FishWorld 调用的世界模型，外部 Agent 的费用不可见。

预算预检使用 UTF-8 消息长度及封装余量、保守输入价格和最大输出量估算。服务商隐藏封装、计费更新时间或价格变化仍可能使实际费用偏离。自定义兼容服务商的价格未登记时费用为未知，不能按 0 元继续自动游玩。可由本地所有者通过 `FISHWORLD_CUSTOM_PRICING_FILE` 指定 JSON 文件，其中 `providers` 数组每项按准确的 `base_url`、`model` 匹配，并填写每百万 Token 的 `input_hit`、`input_miss`、`output` 人民币非负有限单价。预检采用两种输入单价中较高者；实际响应缺少缓存分项时按未命中估算并注明。此类金额明确标注为所有者配置的估算；官方 DeepSeek 地址忽略这些覆盖，继续使用内置官方峰谷价格表。

网络失败和超时不自动重试，避免将未知结果的计费请求重复发送。HTTP 错误不展示服务商响应正文或 URL，避免回显密钥和私人上下文。成功 HTTP 响应里的截断/空白输出仍返回实际用量，交由会话层登记失败尝试，不能冒充成功世界回复。Mock Provider 完全离线、不用真实 Token；相关测试只证明程序上下文和保存逻辑，不能证明真实模型的语义理解或真实缓存命中。

世界模型的规则和固定设定保持静态；历史窗口定期缩短时，较早的消息前缀会按预期失效，原始事件仍留在数据库。API 临时玩家的 Core 与可选记忆保持静态；欢迎说明仅在第一次决策提供，第二次请求移除它会造成一次预期的前缀失效。此后最近记录窗口变化仍可能降低命中率。真实五轮验收验证的是世界模型的连续缓存，不能据此声称 API 玩家也经过线上缓存验收。

配置只使用 API Key 的环境变量名，例如 `DEEPSEEK_API_KEY`；不将 Key 记录到源码、世界日志或共享导出。核心设定和必要上下文在 API 模式会发送给所选模型服务商，默认只保存在本地私有数据目录。
